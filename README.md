# FAST and EASY — classic version

Эта версия возвращена к простому формату: `index.html`, `styles.css`, `script.js` и `assets/`.

Для просмотра можно открыть `index.html` в браузере. Для корректной работы лучше использовать Live Server в VS Code.

Фотографии по-прежнему загружаются по внешним ссылкам Unsplash. Телефон, адрес, цены и демонстрационные материалы нужно заменить реальными данными перед публикацией.
