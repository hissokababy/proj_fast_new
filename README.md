# FAST and EASY — classic HTML version

## Переводы через JSON

Все видимые текстовые фрагменты страницы хранятся в `texts.json`. Структура словаря:

- `languages` — массив языков;
- `ru` / `uz` — код языка, название и флаг;
- `categories` — категории с английскими названиями;
- внутри категорий — английские ключи и значения на выбранном языке.

В `index.html` текстовые фрагменты заменены пустыми элементами с `data-i18n="category.key"`. `script.js` загружает `texts.json` через `fetch()` и подставляет значения. Переводы атрибутов (alt, placeholder, aria-label, title) задаются через `data-i18n-attr`.

## Запуск

Открой папку в VS Code и запусти `index.html` через расширение Live Server. Не открывай HTML двойным щелчком через `file://`, потому что браузер может блокировать загрузку JSON.

## Настройка

Добавляй тексты в `texts.json`, используя английские имена категорий и ключей. Для нового текста в HTML укажи `data-i18n="category.key"`; сам текст хранить в HTML не нужно.
